# Color Picker App 🎨

A simple and interactive web application built with vanilla JavaScript that allows users to pick colors in real-time and instantly view their HEX color codes.

## Features ✨
* **Interactive Color Input:** Uses HTML5 color picker to select any color dynamically.
* **Real-time Updates:** Instantly updates the background display box and displays the exact HEX code.
* **Clean UI:** Styled with a modern, minimalist container and smooth transitions.

## Tech Stack 🛠️
* **HTML5:** Structure and markup.
* **CSS3:** Styling, flexbox layout, and transitions.
* **JavaScript (Vanilla):** DOM manipulation and event listeners.
